# 03 存储与分类

> 状态：草稿 ｜ 更新：2026-10-30

## 1. 场景

| 场景 | 期望 |
|---|---|
| Excel 正在打开，同时按快捷键保存 | 照常保存，不排队等待 |
| 想只看"所有 AI 问答"或"所有随手记" | 能按类别查看，各类别分开存放 |
| 以后调整了分类方式 | 已有的记录能按新方式重新整理，原始内容不受影响 |
| Cursor 升级、清理了本地会话文件，或者换了电脑 | v2 里已经保存的问答仍然完整 |
| v1 用了好几年的 Excel 知识库 | 这些历史记录能进入 v2，一起搜索和关联 |
| v2 开发过程中把数据弄乱了 | 不影响 v1 日常使用的数据 |

## 2. 需求清单

| 编号 | 需求 | 优先级 | 来源 | 验收标准 |
|---|---|---|---|---|
| STO-01 | v2 的主存储是本地 SQLite，保存和查看都不依赖 Excel 是否打开 | P0 | 用户 | Excel 打开期间，保存、搜索、浏览全部正常 |
| STO-02 | v2 使用独立的数据库文件名，和 v1 的 `shouyu.db` 分开 | P0 | 用户 | v1 和 v2 的数据库文件互不读写 |
| STO-03 | 信息不只存在 SQLite 里，也允许以本地文件的形式存放，比如问答原文、大附件 | P0 | 用户 | 不规定所有内容都必须进数据库 |
| STO-04 | 原始记录完整保留，写入后不修改 | P0 | 用户 | 任何一条分类后的记录都能追溯到它的原始记录 |
| STO-05 | 按类别分开存放：随手记、截图、任务、Backlog、番茄、习惯、AI 问答、网页片段等 | P0 | 用户 | 能按类别浏览；每个类别有自己需要的字段，比如任务有状态和优先级，问答有会话和轮次 |
| STO-06 | 分类方式可以调整，调整后已有的记录能重新分类 | P1 | 建议 | 修改分类规则后，执行一次重新整理，结果符合新规则，原始记录不变 |
| STO-07 | v2 自己保存一份 Cursor 问答，不依赖 Cursor 的本地文件一直存在 | P0 | 建议 | 删除 Cursor 的本地会话文件后，v2 里的问答仍然完整 |
| STO-08 | 能把 v1 Excel 里的历史记录导入 v2：每日随手记、任务、Backlog、番茄记录、反思 | P0 | 建议 | 抽查任意一天，v2 里的内容和 Excel 当天的工作表一致 |
| STO-09 | v1 和 v2 可以共用同一个 Excel 文件 | 待定 | 用户 | 具体是"v2 只读导入"、"v2 也写入"还是"v2 导出给手机看"，见 Q1 |
| STO-10 | 数据能备份和恢复 | P0 | 用户（v1 已有，针对 Excel） | 能回到最近的任意一个备份点；备份不需要停止程序 |
| STO-11 | v2 升级后，旧版本保存的数据能继续使用 | P0 | 建议 | 升级前保存的记录，升级后仍能正常打开和搜索 |
| STO-12 | 数据能完整导出成通用格式，比如 Markdown 或 JSON | P2 | 建议 | 不依赖 shouyu 程序，也能阅读导出的内容 |
