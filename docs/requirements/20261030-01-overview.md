# 01 总览：背景、愿景与范围

> 状态：草稿 ｜ 更新：2026-10-30

## 1. 背景

### 1.1 v1 是什么

shouyu v1 是一个 Windows 上的"随手记"工具。它通过全局快捷键，把剪贴板里的文字和图片记进 Excel，每天一个工作表。它还内置了每日任务、Backlog、习惯提醒、番茄钟。

### 1.2 v1 的痛点

| # | 痛点 | 表现 |
|---|---|---|
| 1 | Excel 打开慢 | 每次查看都要等 Excel 或 WPS 加载整个工作簿 |
| 2 | Excel 打开期间无法写入 | 新记录只能留在队列里排队，要等 Excel 关闭后才能写进去 |
| 3 | 工作簿越大越慢 | 例如 2026-10-21 修复的习惯窗口卡死：刷新一次需要约 262 秒 |
| 4 | 信息分散 | Cursor、Qwen、元宝里的问答，以及随手记，各自存放，没有统一的地方查找 |
| 5 | 缺少上下文 | 过一段时间回看记录时，不知道当时在做什么、为什么记，很难看懂 |
| 6 | 无法检索 | 只能打开 Excel 按日期翻找，没有跨天、跨来源的搜索 |

## 2. 愿景

做一个本地的**第二大脑**：

- 把各处产生的信息（随手记、截图、任务、番茄、AI 问答、网页）集中保存。
- 按类别分开存放，并且通过时间、任务、项目、内容等线索把它们互相关联，形成一张信息网络。
- 遇到问题时，先查自己的历史，再结合外部搜索和大模型自身的知识，做到快速搜索、联想和辅助决策。

## 3. 目标

| 场景 | 期望 |
|---|---|
| 正在看资料或写代码，想记下一段内容 | 一个快捷键就能保存，不切换窗口，不打断思路 |
| 在 Cursor 里和 AI 讨论了一个问题 | 不需要任何操作，问答会自动、持续地保存下来 |
| 在 Qwen 或元宝上问了问题 | 能把这次问答保存到同一个地方 |
| 一个月后想找"上次那个问题是怎么解决的" | 能搜到，并且能看到当时在做哪个任务、哪个项目、改了哪些文件 |
| 准备开始一个新问题 | 先看到自己以前相关的记录和结论，在这个基础上问出更有价值的问题 |
| 在 Cursor 里让 AI 帮忙 | AI 能查到我自己的历史记录，作为回答的参考 |
| 想回顾某一天或某个时间段 | 能看到那段时间里各个来源的全部记录 |

## 4. 版本关系（来源：用户）

| 项 | 约定 |
|---|---|
| v1 | 继续日常使用。基于 Excel 的小想法和小改进都在 v1 里做 |
| v2 | 新架构的实现。v1 里好的功能逐步迁移到 v2，持续完善 |
| 分支 | `v1`、`v2` 两个分支；版本标记可以考虑用 git tag |
| 数据库 | v2 使用新的数据库文件名，和 v1 分开，互不影响开发 |
| Excel | 可以考虑 v1 和 v2 共用同一个 Excel 文件（具体含义见 [待确认问题](20261030-99-open-questions.md) Q1） |
| 存储形态 | SQLite 是 v2 信息的主要目的地，但不是唯一的存放地方，也可以有本地文件 |
| 界面 | v2 不再用 Excel 作为展示界面，改为自建界面 |

## 6. 用户与使用环境

| 项 | 说明 |
|---|---|
| 用户 | 仅本人一人 |
| 系统 | Windows 10/11，工作电脑，经常插拔外接显示器 |
| 工作内容 | 以写代码为主，同时在多个仓库工作，比如 `sand-api`、`sand-console`、`newton-fe`、`shouyu` |
| AI 工具 | Cursor（主要）、Qwen、元宝 |
| 敏感性 | 记录中包含公司代码、数据库连接信息、业务数据 |

## 7. 术语

| 术语 | 含义 |
|---|---|
| 记录 | v2 里保存的任意一条信息：一条随手记、一张截图、一个任务、一个番茄、一次问答、一个网页片段 |
| 来源 | 记录是从哪里来的：剪贴板、截图 OCR、Cursor、Qwen、元宝、任务面板、番茄钟等 |
| 原始记录 | 采集时拿到的原样内容，没有经过分类和加工 |
| 类别 | 记录的种类，比如随手记、任务、番茄、问答、网页 |
| 上下文 | 产生一条记录时周围的情况：当时的时间、正在做的任务、所在的项目和文件、前台窗口、网址 |
| 关联 | 两条记录之间的关系，以及产生这个关系的原因 |
| 工作片段 | 一段时间上连续的工作，比如一个番茄，或者两次长时间空闲之间的那段时间 |
| 会话 | 一次 AI 对话，包含多轮问答 |
