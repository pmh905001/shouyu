# 今日任务、番茄、上一条记录改为以 SQLite 为主

> 状态：草稿 ｜ 更新：2026-10-31
>
> 对应路线图 M5 里"任务和番茄"这一部分，以及 M1 里的一小部分（剪贴板记录写入 SQLite），提前做（见第 8 节 T-Q7）。
> 依据：v2 分支起点 `ba6c474` 的代码。设计见 [design/planning/20261031-01-tasks-to-sqlite.md](../../design/planning/20261031-01-tasks-to-sqlite.md)。

## 1. 背景

### 1.1 现在的情况

下面这些功能，现在都直接读写 Excel：

| 功能 | 读 Excel | 写 Excel |
|---|---|---|
| 晨间仪式窗口 `ctrl+alt+h` | 今日任务、两类 Backlog、历史日期的任务、今日番茄数 | 保存今日任务和 Backlog；把历史任务标为完成 |
| 今日任务面板 `ctrl+alt+反引号` | 今日任务 | 保存今日任务 |
| 番茄钟 | 当前进行中的任务名 | 每完成一个番茄，写一行"🍅 50min @09:00-09:50" |
| 查看上一条记录 `alt+/` | 加载整个 Excel，找出今天工作表里最后一个有内容的单元格或图片，弹出提示 | |
| 保存剪贴板、截图、OCR | | 写进今天工作表的"其他"区域 |

数据在 Excel 里的存放方式：

| 数据 | 存放位置 |
|---|---|
| 今日任务：文字、状态、优先级、预估时长、反思、工作或生活 | 当天工作表的计划区，用字体颜色表示状态 |
| 历史日期的任务 | 那一天的工作表 |
| 工作 Backlog、生活 Backlog | `backlog-work`、`backlog-life` 两张工作表 |
| 番茄记录 | 当天工作表里以 🍅 开头的行，番茄数靠数这些行 |
| 剪贴板、截图、OCR 的记录 | 当天工作表的"其他"区域 |

### 1.2 问题

| 问题 | 表现 |
|---|---|
| 打开慢 | `ctrl+alt+h` 每次都要加载整个 Excel，2026-10-21 修复后仍需约 2 秒；`alt+/` 也要加载整个 Excel |
| Excel 打开时存不进去 | 保存要在队列里排队，等 Excel 关闭后才真正写入，在那之前重新打开窗口看不到改动 |
| 番茄记录可能失败 | 番茄钟直接写 Excel，Excel 被占用时写入失败 |
| 任务没有身份 | 任务靠行号识别，结转、移进 Backlog 后，就认不出是同一个任务 |

### 1.3 用户的决定（2026-10-31）

- 今日任务、晨间仪式窗口展示的信息，都从 SQLite 读写，不再依赖 Excel 文件。
- 以 SQLite 为主，Excel 只作为展示信息的方式之一。
- `alt+/` 不再读 Excel，改为从 SQLite 读取。
- `ctrl+alt+h` 从 SQLite 读取和写入。
- 番茄钟所有读写 Excel 的地方，都改为读写 SQLite。

## 2. 目标

| 场景 | 期望 |
|---|---|
| 按 `ctrl+alt+h` | 窗口很快打开，今日任务、Backlog、历史任务都从 SQLite 读取 |
| 编辑任务后按"开始今天"或关闭 | 立即保存到 SQLite，Excel 是否打开都没有影响 |
| 专注、完成一个番茄 | 番茄钟从 SQLite 读当前任务，把番茄记录写进 SQLite |
| 按 `alt+/` | 立即显示上一条保存的记录，不加载 Excel |
| 习惯了现在的操作 | 所有操作、快捷键、界面和现在一样 |
| 还想在 Excel 里看 | Excel 里继续能看到任务、Backlog、番茄、剪贴板记录，只是它变成了从 SQLite 同步过去的副本 |
| 已经在 Excel 里积累了历史任务 | 切换后，历史任务、Backlog、番茄记录都还在 |

## 3. 范围

### 3.1 包含

| 功能 | 说明 |
|---|---|
| 晨间仪式窗口（`ctrl+alt+h`） | 今日任务、工作和生活 Backlog、历史日期的未完成任务、结转、今日复盘 |
| 今日任务面板（`ctrl+alt+反引号`） | 它和晨间仪式窗口读写同一份今日任务，必须一起切换，否则两边数据会不一致 |
| 番茄钟里所有读写 Excel 的地方 | 读取当前进行中的任务名；保存每个番茄的记录；统计今日和历史日期的番茄数 |
| 查看上一条记录（`alt+/`） | 从 SQLite 读取 |
| 剪贴板、截图、OCR 的保存 | 先写进 SQLite，再同步到 Excel。这是 `alt+/` 能从 SQLite 读到内容的前提 |
| 同步到 Excel | 任务、Backlog、番茄、剪贴板记录都同步到 Excel，作为展示 |
| Excel 历史导入 | 把 Excel 里已有的任务、Backlog、番茄记录导入 SQLite |

### 3.2 不包含

| 功能 | 说明 |
|---|---|
| 剪贴板记录的上下文（前台程序、窗口标题、网址、当时的任务） | 属于路线图 M1 的 CAP-03 |
| 导入 Excel 里历史的剪贴板、截图记录 | 属于路线图 M4 的 STO-08（见 T-Q10） |
| 习惯列表 | 仍然保存在 `kb.ini` |
| 连续天数、"今天已弹出"、番茄钟的恢复状态 | 仍然保存在 `shouyu_state.json` |
| 番茄钟本身的计时、提醒、走神检测等 | 不改 |
| `ctrl+\` 打开 Excel、`ctrl+q` 关闭 Excel | 不改，用来查看 Excel 里的展示 |
| `ctrl+F9` 单元格模式 | 只影响 Excel 里的排版，不改（INH-05） |
| v2 自己的浏览和搜索界面 | 属于路线图 M2 |
| v1 分支 | 不改。需要以 Excel 为主的版本时，使用 v1 |

## 5. 必须保持一致的操作（PLN-02 的检查清单）

| 类别 | 操作 |
|---|---|
| 今日任务 | 新增、编辑、删除；上移、下移；4 种状态：待办、进行中、挂起、完成；同一时间只有一个进行中 |
| 任务属性 | 优先级 P1、P2、P3；预估时长，新建后自动弹出时长选择；工作或生活；完成后写反思，3 种反思提示方式 |
| Backlog | 工作、生活两个区；新增、编辑、删除、排序；改为另一类时保留"已搁置 N 天"；拉到今日；从今日移入 |
| 拖拽 | 今日、工作 Backlog、生活 Backlog 之间拖拽，以及各自列表内排序 |
| 历史日期 | 自动选最近 30 天内有任务的一天；1、2、3 天前；自选日期；显示那天"完成数/总数"和番茄数 |
| 结转 | 勾选历史日期的未完成任务带到今天，已经在今天的不重复添加；把历史任务标为已完成 |
| 清理 | "清理未完成 → Backlog"，按工作或生活分开，按文字去重 |
| 统计和复盘 | 完成数、进行中、挂起、P1 数量、工作和生活数量、已估时、未估时、超载提醒、进度条；今日复盘（估时和实际番茄时间对比） |
| 编辑行为 | 撤销、重做；所有快捷键；关闭时如果有未保存的改动，提示保存 |
| 和番茄钟联动 | "专注此项"开始番茄；切换进行中的任务时，悬浮窗的任务名同步变化 |
| 保存记录 | `ctrl+shift+enter` 按 1 次和快速按 2 次；`ctrl+c` 连按 2 次和 3 次；截图键；`ctrl+alt+o`；保存后的气泡提示 |
| 查看上一条 | `alt+/` 弹出提示，显示内容或图片预览 |
| 其他 | 保存后的提示；连续天数；习惯列表的编辑 |

## 6. 和 Excel 的关系

| 情况 | 期望 |
|---|---|
| Excel 文件不存在、损坏或被占用 | 第 3.1 节的功能全部正常，只是同步到 Excel 的内容排队等待 |
| 在 Excel 里直接修改任务 | 不会读回 SQLite；下次同步时，Excel 里的计划区和 Backlog 会被 SQLite 的内容覆盖（见 T-Q4） |
| 在 Excel 里看当天的内容 | 和现在一样：计划区、进行中的任务和番茄行、"其他"区域里的剪贴板记录 |
| 需要回到以 Excel 为主的方式 | 使用 v1（见 T-Q8） |

## 7. 前提和风险

| 项 | 说明 |
|---|---|
| v2 分支现在的 `kb.ini` | 数据库、日志、Excel 都用绝对路径指向 v1 正在使用的文件（路线图 M0 要解决的问题）。开发和测试时，必须改用单独的 Excel 副本和数据库，否则会改到 v1 的日常数据 |
| v1 和 v2 同时运行 | 两边都会写同一个 Excel，会互相覆盖（见总览的 Q2）；快捷键也会冲突 |
