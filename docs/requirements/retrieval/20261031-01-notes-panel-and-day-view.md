# 记录面板（`alt+/`）和日视图

> 状态：已实现，待审核 ｜ 更新：2026-10-31
>
> 对应路线图 M2"能看能搜"里的一部分：RET-01（只含记录）、RET-05（只含复制和定位，不含关联）、RET-06。
> 前提：[planning/20261031-01-tasks-to-sqlite.md](../planning/20261031-01-tasks-to-sqlite.md) 已实现，任务、番茄、剪贴板记录都已经以 SQLite 为主。
> 设计见 [design/retrieval/20261031-01-notes-panel-and-day-view.md](../../design/retrieval/20261031-01-notes-panel-and-day-view.md)。

## 1. 背景

### 1.1 现在的情况

| 功能 | 现在的做法 |
|---|---|
| `alt+/` | 从 SQLite 读最近保存的**一条**剪贴板、截图或 OCR 记录，弹出一个提示（PLN-14） |
| 找以前存过的东西 | 按 `ctrl+\` 打开 Excel，切到那一天的工作表，用 Excel 的查找 |
| 看一天的全貌 | 在 Excel 的当天工作表里看：计划区、🍅 行、"其他"区域 |
| 改任务、补记录 | 在 Excel 里改；但现在以 SQLite 为主，Excel 里改的内容不会读回（PLN-03） |

### 1.2 问题

| 问题 | 表现 |
|---|---|
| `alt+/` 信息太少 | 只能看到最后一条，想看前面几条只能去 Excel |
| 搜索不方便 | 要先打开 Excel（慢），再切工作表；跨天搜索要一张张工作表找 |
| Excel 改了不算数 | 以 SQLite 为主之后，Excel 只能看，不能改；需要一个能改 SQLite 数据的地方 |
| 历史记录不在 SQLite | 2026-10-31 之前存的剪贴板、OCR 文字还只在 Excel 里，在 v2 里搜不到（见 R-Q5） |

### 1.3 用户的想法（2026-10-31）

- `alt+/` 要能看到更多最近的记录，用消息气泡显示，做一套新的界面。
- 新界面要能快速搜索，输入一两个字就能搜到今天的记录。
- 还要能搜昨天、前天，以及全部记录。
- 做一个类似 Excel 的界面，读取 SQLite 里的数据，能编辑、保存；定义一个新的快捷键打开它。有现成的开源软件也可以用。

## 2. 目标

| 场景 | 期望 |
|---|---|
| 刚存了几段东西，想看看 | 按 `alt+/`，弹出记录面板，以气泡显示今天的记录，最新的在最下面 |
| 想找今天存过的一段话 | 在面板里直接打一两个字，列表立即只剩匹配的记录 |
| 想找昨天、前天或更早存过的 | 同一个搜索框，结果按天分组，今天的在最前；也可以一键只看某一天 |
| 找到了要用 | 回车，内容回到剪贴板，可以直接粘贴 |
| 想回顾某一天 | 按新快捷键打开日视图，像 Excel 的一张日工作表：任务、番茄、记录都在一页 |
| 发现某天的任务状态、名字不对 | 在日视图里直接改，保存进 SQLite |
| 习惯了 Excel | `ctrl+\` 继续打开 Excel 看同步过去的副本 |

## 3. 范围

### 3.1 包含

| 功能 | 说明 |
|---|---|
| 记录面板 | 由 `alt+/` 打开，取代现在的单条提示 |
| 记录的搜索 | 文字和 OCR 记录的内容；今天、昨天、前天、近 7 天、全部 |
| 记录的复制、查看、删除、修改文字 | 在记录面板和日视图里都能做 |
| 日视图 | 新快捷键打开；按天查看和编辑任务、查看番茄、查看和编辑记录；编辑 Backlog |
| 导入 Excel 里历史的剪贴板、OCR 文字 | 只导入文字，图片留在 Excel（R-Q5） |

### 3.2 不包含

| 功能 | 说明 |
|---|---|
| 搜索任务、反思、番茄 | 本次只搜记录（R-Q1）。全局搜索所有类别属于 RET-01 的后续部分 |
| 截图里的文字搜索 | 需要给截图做本地 OCR，放到以后（R-Q6） |
| 关联记录、跳回 Cursor 会话或网页 | 属于路线图 M3、M6 |
| 记录的上下文（前台程序、窗口标题、网址） | 属于路线图 M1 的 CAP-03 |
| 像 Excel 一样在任意格子里自由写内容 | 日视图按"任务、番茄、记录"的结构展示，不支持自由格子（R-Q4） |
| 用通用的 SQLite 工具（DB Browser for SQLite 等）作为日常编辑入口 | 只作为查看和核对数据的工具，见设计第 3.6 节 |
| 晨间仪式窗口、今日任务面板 | 不改 |
| 把记录的修改、删除同步到 Excel | 不同步（R-Q3） |

## 5. 和 Excel 的关系

| 情况 | 期望 |
|---|---|
| `ctrl+\` | 不变，继续打开 Excel 看同步过去的副本 |
| 在日视图里改了任务 | 和晨间仪式窗口一样，同步到 Excel 那一天的计划区 |
| 在记录面板或日视图里删除、修改了一条记录 | Excel 里"其他"区域原有的那一条不变（R-Q3） |
| 日视图稳定以后 | 可以考虑让 `ctrl+\` 改为打开日视图，Excel 改用别的快捷键（R-Q7） |

## 6. 前提和风险

| 项 | 说明 |
|---|---|
| `kb.ini` 的 `excel_path` | 还指向 v1 正在用的真实 Excel（路线图 M0）。v2 里在日视图改的任务会同步进这个文件 |
| 历史记录 | 如果不做 REC-18，记录面板的"全部"只包含 2026-10-31 以后存的记录 |
| `ctrl+c` 连按 2 次会保存剪贴板 | 这是现有的全局快捷键。在日视图里连按 2 次 `ctrl+C` 复制格子时，也会多存一条记录。和在其他程序里的表现一样，不单独处理（R-Q8） |
| 新快捷键冲突 | `ctrl+alt` 组合在部分键盘布局下等同于 `AltGr`，可能和输入法冲突，要先在实际电脑上试 |
