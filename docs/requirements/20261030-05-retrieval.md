# 05 检索、展示与辅助决策

> 状态：草稿 ｜ 更新：2026-10-30

## 1. 场景

| 场景 | 期望 |
|---|---|
| 突然想起"以前好像查过这个" | 一个快捷键弹出搜索框，输入几个字就能找到 |
| 搜到一条结果 | 能看到它的上下文和关联记录，能跳回原处：Cursor 会话、网页、任务 |
| 想回顾一天的工作 | 有一个按天查看的时间线，取代 v1 里"打开 Excel 看当天工作表"的做法 |
| 在 Cursor 里问 AI 一个问题 | AI 先查我的历史，把相关的历史记录作为回答依据 |
| 要做一个决定 | 先看自己以前的记录和结论，再结合外部搜索和大模型的知识，并且能区分哪些信息来自我的历史 |
| 积累了大量问答 | 能把零散的问答提炼成可以复用的结论 |

## 2. 需求清单

### 2.1 检索

| 编号 | 需求 | 优先级 | 来源 | 验收标准 |
|---|---|---|---|---|
| RET-01 | 全局快捷键唤起搜索，一次搜索覆盖所有来源和类别 | P0 | 用户 | 在任何程序里按快捷键都能弹出搜索框 |
| RET-02 | 中文、英文、代码标识符（比如 `HandleChat`、`sand_api`）都能搜到 | P0 | 建议 | 输入中文词、英文词、函数名的一部分，都能命中 |
| RET-03 | 按时间、来源、类别、项目、标签筛选 | P0 | 建议 | 能组合筛选，比如"最近一周 + Cursor + sand-api" |
| RET-04 | 按意思搜索，不只是按字面匹配 | P1 | 用户 | 见 ASC-06 |
| RET-05 | 搜索结果能显示上下文和关联，并能跳回原处 | P0 | 用户 | 能打开原始的 Cursor 会话或网址；问答能定位到具体是哪一轮 |

### 2.2 展示

| 编号 | 需求 | 优先级 | 来源 | 验收标准 |
|---|---|---|---|---|
| RET-06 | 时间线视图：按天查看所有记录 | P0 | 用户 | 能完成 v1 里"打开 Excel 看当天工作表"能做的事 |
| RET-07 | 类别视图：按类别浏览，比如只看问答、只看任务 | P1 | 用户 | 能切换类别 |
| RET-08 | 关联视图：以一条记录为中心，查看它的关联网络 | P1 | 用户 | 见 ASC-10 |
| RET-09 | 能在手机、平板等其他设备上查看 | 待定 | 用户（v1 的优点之一：Excel 在各个平台都能打开） | 见 Q4 |

### 2.3 辅助决策

| 编号 | 需求 | 优先级 | 来源 | 验收标准 |
|---|---|---|---|---|
| RET-10 | Cursor 等 AI 工具能查询我的历史记录 | P1 | 用户 | 在 Cursor 里问"我之前怎么处理过 X"，AI 能引用 v2 里的记录作答 |
| RET-11 | 提问时先找我自己的历史，再结合外部搜索和大模型的知识 | P1 | 用户 | 回答里能分清哪些来自我的历史、哪些来自外部 |
| RET-12 | 联想：查看一条记录时，主动列出可能相关的其他记录 | P1 | 用户 | 打开一条记录，旁边能看到"可能相关"的列表 |
| RET-13 | 提炼：把一段时间的问答整理成"问题、原因、解决办法"形式的结论 | P2 | 建议 | 能对选中的会话生成结论；生成的结论本身也作为一条记录，并关联到来源会话 |
