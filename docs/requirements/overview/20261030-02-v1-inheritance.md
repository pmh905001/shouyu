# v1 功能继承清单

> 状态：草稿 ｜ 更新：2026-10-31
>
> 依据：v2 分支起点 `ba6c474` 的代码、`kb.ini` 和 README 更新日志。
> "处置"一列是整理时给出的建议，需要用户逐项确认（见 Q6）。
>
> 第 2 节列出的功能在 v1 里都已经实现，已逐项对照代码核实。v2 里目前一项都还没有迁移。每迁移完成一项，就更新"v2 现状"一列。

## 1. 处置的含义

| 处置 | 含义 |
|---|---|
| 迁移 | v2 保留这个功能，用户感受到的行为和 v1 一致 |
| 调整 | v2 保留这个功能的目的，但行为会变化，因为它原本依赖 Excel |
| 废弃 | v2 不再需要，因为它只是为了解决 Excel 带来的问题 |
| 暂缓 | v2 第一个可用版本不做，以后再说 |

"v2 现状"的取值：`未迁移`、`已迁移`、`已废弃`（处置为废弃并已确认）。
